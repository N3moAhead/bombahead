Go Bot Tutorial

This guide shows how to build a minimal BombAhead bot with Go, test it locally, package it as a container image, and push it to ghcr.io so you can register it on the platform later.

Note: This page is a practical tutorial. The old content was only added for testing and has been replaced.

1. Prerequisites

  • Go 1.23+
  • Docker
  • A GitHub account (for ghcr.io)

Podman works as well. You can replace docker with podman in the commands below.

2. Create a new bot project

1mkdir my-bombahead-go-bot
2cd my-bombahead-go-bot
3go mod init github.com/<your-user>/my-bombahead-go-bot
4go get github.com/N3moAhead/bombahead-go

Recommended structure:

1my-bombahead-go-bot/
2  go.mod
3  go.sum
4  cmd/
5    bot/
6      main.go

3. Write a minimal bot

Create cmd/bot/main.go:

 1package main
 2
 3import (
 4	"log"
 5
 6	bombahead "github.com/N3moAhead/bombahead-go"
 7)
 8
 9type SimpleBot struct{}
10
11func (b *SimpleBot) GetNextMove(state *bombahead.GameState, h *bombahead.GameHelpers) bombahead.Action {
12	if state == nil || state.Me == nil {
13		return bombahead.DoNothing
14	}
15
16	me := state.Me.Pos
17
18	if !h.IsSafe(me) {
19		safe := h.GetNearestSafePosition(me)
20		return h.GetNextActionTowards(me, safe)
21	}
22
23	boxPos, found := h.FindNearestBox(me)
24	if found {
25		dist := me.DistanceTo(boxPos)
26		if dist == 1 {
27			return bombahead.PlaceBomb
28		}
29		if dist > 1 {
30			return h.GetNextActionTowards(me, boxPos)
31		}
32	}
33
34	return bombahead.DoNothing
35}
36
37func main() {
38	log.Println("Starting SimpleBot...")
39	bombahead.Run(&SimpleBot{})
40}

4. Learn the basic SDK concepts

The only interface you must implement:

1type Bot interface {
2    GetNextMove(state *GameState, helpers *GameHelpers) Action
3}

Entry point:

1func Run(userBot Bot)

Run(...) handles:

  • WebSocket connection
  • ready-state updates
  • state parsing each tick
  • helper construction
  • sending your returned action

Important actions:

  • MoveUp
  • MoveDown
  • MoveLeft
  • MoveRight
  • PlaceBomb
  • DoNothing

Useful helpers to start with:

  • IsSafe(pos)
  • GetNearestSafePosition(pos)
  • FindNearestBox(pos)
  • GetNextActionTowards(start, target)

5. Run and test locally

Run your bot:

1go run ./cmd/bot

For a realistic local test, run server + a default opponent image, then your bot.

Default images used by BombAhead tooling:

  • Server: ghcr.io/n3moahead/bombahead/os-server:latest
  • Opponent (aggressive): ghcr.io/n3moahead/bomber:self-destruct
  • Opponent (passive): ghcr.io/n3moahead/bomber:idle
1# Terminal 1: game server
2docker run --rm -p 8038:8038 ghcr.io/n3moahead/bombahead/os-server:latest
3
4# Terminal 2: default opponent
5docker run --rm --network host ghcr.io/n3moahead/bomber:idle
6
7# Terminal 3: your bot from source
8go run ./cmd/bot

Your bot should connect to ws://localhost:8038/ws.

6. Containerize your bot

Create a Dockerfile:

 1FROM docker.io/golang:1.25-alpine AS builder
 2WORKDIR /app
 3
 4COPY go.mod go.sum ./
 5RUN go mod download
 6
 7COPY . .
 8RUN go build -o /app/bot ./cmd/bot/main.go
 9
10FROM docker.io/alpine:latest
11WORKDIR /root/
12COPY --from=builder /app/bot .
13
14CMD ["./bot"]

Build locally:

1docker build -t my-bombahead-go-bot:local .

7. Push to GitHub Container Registry (ghcr.io)

Choose your final image name, for example:

ghcr.io/<github-username>/bombahead-go-bot:v1

Login:

1echo <YOUR_GITHUB_PAT> | docker login ghcr.io -u <github-username> --password-stdin

Tag and push:

1docker tag my-bombahead-go-bot:local ghcr.io/<github-username>/bombahead-go-bot:v1
2docker push ghcr.io/<github-username>/bombahead-go-bot:v1

Important: ghcr.io images are usually private by default. Make your package/image public, otherwise the BombAhead match runner cannot pull it and your matches will fail before game start.

GitHub visibility path (typical):

  • GitHub profile/org
  • Packages
  • Your container package
  • Package settings
  • Change visibility to Public

8. Register bot on BombAhead

After your image is public and pullable:

  1. Log in to BombAhead
  2. Open /bots/new
  3. Enter bot name + description
  4. Paste your image URL, e.g. ghcr.io/<github-username>/bombahead-go-bot:v1
  5. Save

After that, BombAhead can schedule matches for your bot.
