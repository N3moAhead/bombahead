Python Bot Tutorial

This guide shows how to build a minimal BombAhead bot with Python, test it locally, package it as a container image, and push it to ghcr.io so you can register it on the platform later.

Note: This page is a practical tutorial. For detailed API reference, consult the SDK's source or README.

1. Prerequisites

  • Python 3.10+
  • Docker
  • A GitHub account (for ghcr.io)

Podman works as well. You can replace docker with podman in the commands below.

2. Create a new bot project

1mkdir my-bombahead-py-bot
2cd my-bombahead-py-bot
3python3 -m venv venv
4source venv/bin/activate
5pip install bombahead-py

Recommended structure:

1my-bombahead-py-bot/
2  bot.py
3  requirements.txt

Create a requirements.txt:

1bombahead-py

3. Write a minimal bot

Create bot.py:

 1from bombahead import Action, Bot, GameHelpers, GameState, run
 2
 3class SimpleBot(Bot):
 4    def get_next_move(self, state: GameState, helpers: GameHelpers) -> Action:
 5        # If our bot is not initialized or dead, do nothing
 6        if not state.me:
 7            return Action.DO_NOTHING
 8
 9        me_pos = state.me.pos
10
11        # If our tile is unsafe, move to the nearest safe tile.
12        if not helpers.is_safe(me_pos):
13            safe_pos = helpers.get_nearest_safe_position(me_pos)
14            return helpers.get_next_action_towards(me_pos, safe_pos)
15
16        # Otherwise move toward the nearest box.
17        box_pos, found = helpers.find_nearest_box(me_pos)
18        if found:
19            dist = me_pos.distance_to(box_pos)
20            if dist == 1:
21                return Action.PLACE_BOMB
22            if dist > 1:
23                return helpers.get_next_action_towards(me_pos, box_pos)
24
25        return Action.DO_NOTHING
26
27if __name__ == "__main__":
28    print("Starting SimpleBot...")
29    run(SimpleBot())

4. Learn the basic SDK concepts

The architecture of the SDK is built around a simple reactive event loop. Your bot operates as an asynchronous callback invoked upon receiving a state update from the server.

The only interface you must implement is the Bot protocol:

1class Bot(Protocol):
2    def get_next_move(self, state: GameState, helpers: GameHelpers) -> Action: ...

Entry point:

1run(bot)

run(...) handles:

  • WebSocket connection
  • ready-state updates
  • state parsing each tick
  • helper construction
  • sending your returned action

Important actions (Action enum):

  • Action.MOVE_UP
  • Action.MOVE_DOWN
  • Action.MOVE_LEFT
  • Action.MOVE_RIGHT
  • Action.PLACE_BOMB
  • Action.DO_NOTHING

Useful helpers to start with (GameHelpers):

  • is_safe(pos)
  • get_nearest_safe_position(pos)
  • find_nearest_box(pos)
  • get_next_action_towards(start, target)

5. Run and test locally

Run your bot:

1python bot.py

For a realistic local test, run server + a default opponent image, then your bot.

Default images used by BombAhead tooling:

  • Server: ghcr.io/n3moahead/bombahead/server:latest
  • Opponent (aggressive): ghcr.io/n3moahead/bomber:self-destruct
  • Opponent (passive): ghcr.io/n3moahead/bomber:idle
1# Terminal 1: game server
2docker run --rm -p 8038:8038 ghcr.io/n3moahead/bombahead/server:latest
3
4# Terminal 2: default opponent
5docker run --rm --network host ghcr.io/n3moahead/bomber:idle
6
7# Terminal 3: your bot from source
8python bot.py

Your bot should connect to ws://localhost:8038/ws.

6. Containerize your bot

Create a Dockerfile:

 1FROM python:3.12-slim
 2
 3WORKDIR /app
 4
 5COPY requirements.txt .
 6RUN pip install --no-cache-dir -r requirements.txt
 7
 8COPY bot.py .
 9
10CMD ["python", "bot.py"]

Build locally:

1docker build -t my-bombahead-py-bot:local .

7. Push to GitHub Container Registry (ghcr.io)

Choose your final image name, for example:

ghcr.io/<github-username>/bombahead-py-bot:v1

Login:

1echo <YOUR_GITHUB_PAT> | docker login ghcr.io -u <github-username> --password-stdin

Tag and push:

1docker tag my-bombahead-py-bot:local ghcr.io/<github-username>/bombahead-py-bot:v1
2docker push ghcr.io/<github-username>/bombahead-py-bot:v1

Important: ghcr.io images are usually private by default. Make your package/image public, otherwise the BombAhead match runner cannot pull it and your matches will fail before game start.

GitHub visibility path (typical):

  • GitHub profile/org
  • Packages
  • Your container package
  • Package settings
  • Change visibility to Public

8. Register bot on BombAhead

After your image is public and pullable:

  1. Log in to BombAhead
  2. Open /bots/new
  3. Enter bot name + description
  4. Paste your image URL, e.g. ghcr.io/<github-username>/bombahead-py-bot:v1
  5. Save

After that, BombAhead can schedule matches for your bot.
