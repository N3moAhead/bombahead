Rust Bot Tutorial

This guide shows how to build a minimal BombAhead bot with Rust, test it locally, package it as a container image, and push it to ghcr.io so you can register it on the platform later.

Note: This page is a practical tutorial. For detailed API reference, consult the SDK's source or README.

1. Prerequisites

  • Rust 1.70+
  • Docker
  • A GitHub account (for ghcr.io)

Podman works as well. You can replace docker with podman in the commands below.

2. Create a new bot project

1cargo new my-bombahead-rs-bot
2cd my-bombahead-rs-bot
3cargo add bombahead-rs

Recommended structure:

1my-bombahead-rs-bot/
2  Cargo.toml
3  src/
4    main.rs

3. Write a minimal bot

Replace the contents of src/main.rs with:

 1use bombahead_rs::{Action, Bot, GameState, GameHelpers};
 2
 3struct SimpleBot;
 4
 5impl Bot for SimpleBot {
 6    fn get_next_move(&mut self, state: &GameState, h: &GameHelpers) -> Action {
 7        let me = match &state.me {
 8            Some(player) => &player.pos,
 9            None => return Action::DoNothing,
10        };
11
12        // Run from explosions
13        if !h.is_safe(me) {
14            let safe = h.get_nearest_safe_position(me);
15            return h.get_next_action_towards(me, &safe);
16        }
17
18        // Hunt boxes
19        if let Some(box_pos) = h.find_nearest_box(me) {
20            let dist = me.distance_to(&box_pos);
21            if dist == 1 {
22                return Action::PlaceBomb;
23            } else if dist > 1 {
24                return h.get_next_action_towards(me, &box_pos);
25            }
26        }
27
28        Action::DoNothing
29    }
30}
31
32fn main() {
33    println!("Starting SimpleBot...");
34    bombahead_rs::run(SimpleBot);
35}

4. Learn the basic SDK concepts

The SDK handles connecting to the server over WebSocket, receiving game state messages, building helpers, and sending the returned action to the server.

The only interface you must implement is the Bot trait:

1pub trait Bot {
2    fn get_next_move(&mut self, state: &GameState, helpers: &GameHelpers) -> Action;
3}

Entry point:

1bombahead_rs::run(user_bot)

Important actions (Action enum):

  • Action::MoveUp
  • Action::MoveDown
  • Action::MoveLeft
  • Action::MoveRight
  • Action::PlaceBomb
  • Action::DoNothing

Useful helpers to start with (GameHelpers):

  • is_safe(pos)
  • get_nearest_safe_position(start)
  • find_nearest_box(start)
  • get_next_action_towards(start, target)

5. Run and test locally

Run your bot:

1cargo run

For a realistic local test, run server + a default opponent image, then your bot.

Default images used by BombAhead tooling:

  • Server: ghcr.io/n3moahead/bombahead/server:latest
  • Opponent (aggressive): ghcr.io/n3moahead/bomber:self-destruct
  • Opponent (passive): ghcr.io/n3moahead/bomber:idle
1# Terminal 1: game server
2docker run --rm -p 8038:8038 ghcr.io/n3moahead/bombahead/server:latest
3
4# Terminal 2: default opponent
5docker run --rm --network host ghcr.io/n3moahead/bomber:idle
6
7# Terminal 3: your bot from source
8cargo run

Your bot should connect to ws://localhost:8038/ws.

6. Containerize your bot

Create a Dockerfile:

1FROM rust:1.75 AS builder
2WORKDIR /app
3COPY . .
4RUN cargo build --release
5
6FROM debian:bookworm-slim
7WORKDIR /app
8COPY --from=builder /app/target/release/my-bombahead-rs-bot ./bot
9CMD ["./bot"]

Build locally:

1docker build -t my-bombahead-rs-bot:local .

7. Push to GitHub Container Registry (ghcr.io)

Choose your final image name, for example:

ghcr.io/<github-username>/bombahead-rs-bot:v1

Login:

1echo <YOUR_GITHUB_PAT> | docker login ghcr.io -u <github-username> --password-stdin

Tag and push:

1docker tag my-bombahead-rs-bot:local ghcr.io/<github-username>/bombahead-rs-bot:v1
2docker push ghcr.io/<github-username>/bombahead-rs-bot:v1

Important: ghcr.io images are usually private by default. Make your package/image public, otherwise the BombAhead match runner cannot pull it and your matches will fail before game start.

GitHub visibility path (typical):

  • GitHub profile/org
  • Packages
  • Your container package
  • Package settings
  • Change visibility to Public

8. Register bot on BombAhead

After your image is public and pullable:

  1. Log in to BombAhead
  2. Open /bots/new
  3. Enter bot name + description
  4. Paste your image URL, e.g. ghcr.io/<github-username>/bombahead-rs-bot:v1
  5. Save

After that, BombAhead can schedule matches for your bot.
