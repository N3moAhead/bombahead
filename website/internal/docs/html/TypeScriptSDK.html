TypeScript Bot Tutorial

This guide shows how to build a minimal BombAhead bot with TypeScript, test it locally, package it as a container image, and push it to ghcr.io so you can register it on the platform later.

Note: The legacy client_js/ example in this repository can be outdated. For new bots, use the SDK package bombahead-js.

1. Prerequisites

  • Node.js 20+
  • npm
  • Docker
  • A GitHub account (for ghcr.io)

Podman works as well. You can replace docker with podman in the commands below.

2. Create a new bot project

1mkdir my-bombahead-ts-bot
2cd my-bombahead-ts-bot
3npm init -y

Install dependencies:

1npm install bombahead-js
2npm install -D typescript tsx @types/node

Create a TypeScript config:

1npx tsc --init --rootDir src --outDir dist --module nodenext --target es2022

Update package.json scripts:

1{
2  "scripts": {
3    "dev": "tsx src/bot.ts",
4    "build": "tsc",
5    "start": "node dist/bot.js"
6  }
7}

Recommended structure:

1my-bombahead-ts-bot/
2  src/
3    bot.ts
4  package.json
5  tsconfig.json

3. Write a minimal bot

Create src/bot.ts:

 1import { Action, run, type IBot, type GameState, type GameHelpers } from "bombahead-js";
 2
 3const bot: IBot = {
 4  getNextMove(state: GameState, helpers: GameHelpers): Action {
 5    // If our tile is unsafe, move to the nearest safe tile.
 6    if (!helpers.isSafe(state.me.pos)) {
 7      const safe = helpers.getNearestSafePosition(state.me.pos);
 8      if (safe) {
 9        return helpers.getNextActionTowards(state.me.pos, safe);
10      }
11    }
12
13    // Otherwise move toward the nearest box.
14    const box = helpers.findNearestBox(state.me.pos);
15    if (box) {
16      return helpers.getNextActionTowards(state.me.pos, box);
17    }
18
19    return Action.DO_NOTHING;
20  },
21};
22
23await run(bot);

4. Learn the basic SDK concepts

Your bot gets called every tick via:

1getNextMove(state, helpers)

Most important parts to know first:

  • Action: MOVE_UP, MOVE_DOWN, MOVE_LEFT, MOVE_RIGHT, PLACE_BOMB, DO_NOTHING
  • GameState: me, opponents, players, field, bombs, explosions
  • GameHelpers:
    • isSafe(pos)
    • getNearestSafePosition(pos)
    • findNearestBox(pos)
    • getNextActionTowards(start, target)

The SDK is defensive. If your bot throws or returns an invalid action, it safely falls back to DO_NOTHING.

5. Run and test locally

Build and run locally:

1npm run dev

For a realistic local test, run server + a default opponent image, then your bot.

Default images used by BombAhead tooling:

  • Server: ghcr.io/n3moahead/bombahead/os-server:latest
  • Opponent (aggressive): ghcr.io/n3moahead/bomber:self-destruct
  • Opponent (passive): ghcr.io/n3moahead/bomber:idle
1# Terminal 1: game server
2docker run --rm -p 8038:8038 ghcr.io/n3moahead/bombahead/os-server:latest
3
4# Terminal 2: default opponent
5docker run --rm --network host ghcr.io/n3moahead/bomber:idle
6
7# Terminal 3: your bot from source
8npm run dev

Your bot should connect to ws://localhost:8038/ws (handled by the SDK runtime).

6. Containerize your bot

Create a Dockerfile:

 1FROM docker.io/node:20-alpine
 2
 3WORKDIR /app
 4
 5COPY package.json package-lock.json ./
 6RUN npm ci
 7
 8COPY tsconfig.json ./
 9COPY src ./src
10
11RUN npm run build
12
13CMD ["npm", "start"]

Build locally:

1docker build -t my-bombahead-ts-bot:local .

7. Push to GitHub Container Registry (ghcr.io)

Choose your final image name, for example:

ghcr.io/<github-username>/bombahead-ts-bot:v1

Login:

1echo <YOUR_GITHUB_PAT> | docker login ghcr.io -u <github-username> --password-stdin

Tag and push:

1docker tag my-bombahead-ts-bot:local ghcr.io/<github-username>/bombahead-ts-bot:v1
2docker push ghcr.io/<github-username>/bombahead-ts-bot:v1

Important: ghcr.io images are usually private by default. Make your package/image public, otherwise the BombAhead match runner cannot pull it and your matches will fail before game start.

GitHub visibility path (typical):

  • GitHub profile/org
  • Packages
  • Your container package
  • Package settings
  • Change visibility to Public

8. Register bot on BombAhead

After your image is public and pullable:

  1. Log in to BombAhead
  2. Open /bots/new
  3. Enter bot name + description
  4. Paste your image URL, e.g. ghcr.io/<github-username>/bombahead-ts-bot:v1
  5. Save

After that, BombAhead can schedule matches for your bot.
